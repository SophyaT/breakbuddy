# 音效文件说明

这个目录用于存放提醒音效文件。你需要添加以下音效文件：

1. gentle-chime.mp3 - 温和的铃声
2. nature-birds.mp3 - 自然鸟鸣声
3. meditation-bowl.mp3 - 冥想钵声
4. soft-bell.mp3 - 柔和铃铛声

你可以从以下来源获取免费的音效：

1. Mixkit (https://mixkit.co/free-sound-effects/)
2. Freesound (https://freesound.org/)
3. Zapsplat (https://www.zapsplat.com/)

请确保下载的音效具有合适的许可证（允许商业使用）。

## 推荐的音效特点

1. gentle-chime.mp3
   - 温和、清脆的铃声
   - 持续时间：2-3秒
   - 渐弱效果

2. nature-birds.mp3
   - 轻柔的鸟鸣声
   - 持续时间：3-5秒
   - 自然、舒缓的感觉

3. meditation-bowl.mp3
   - 西藏冥想钵的声音
   - 持续时间：4-6秒
   - 带有悠长的余音

4. soft-bell.mp3
   - 柔和的铃铛声
   - 持续时间：2-3秒
   - 温和、不突兀

## 音频格式要求

- 格式：MP3
- 比特率：128-192kbps
- 采样率：44.1kHz
- 声道：单声道或立体声
- 音量：标准化到 -3dB
